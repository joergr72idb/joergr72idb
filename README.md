### Hi, I'm joergr72idb 👋

8-bit computers on the network: Atari XL/XE, Commodore 64, Schneider/Amstrad CPC and Apple II with
FujiNet, M4 board and friends - games, a mailbox and the toolchains to build them.

#### Games

- [**Retro Tron Battle**](https://github.com/joergr72idb/retro-tron-battle) - network light-cycle duel
  for real Atari XL, C64 and Schneider CPC computers over WiFi, built for Classic Computing 2026
- [**Retro Game Battle**](https://github.com/joergr72idb/retro-game-battle) - its multi-game successor:
  Tron, Snake, Pong and Artillery on Atari, C64, CPC and Apple II
- [**NEON GRID**](https://github.com/joergr72idb/neon-grid) - light-cycle duel in the browser, with
  LAN-party and offline access-point mode

#### Mailbox

- [**Berlin Blues BBS**](https://github.com/joergr72idb/atari-fujinet-berlin-blues-bbs) - revival of a
  1987 club mailbox on an Atari XL with FujiNet; call it via telnet from a PC, Atari, C64 or CPC
- [**cpc-telnet**](https://github.com/joergr72idb/cpc-telnet) - telnet client for the Schneider CPC
  with the M4 board, made for the Berlin Blues BBS

#### Development kits (macOS and Linux)

Self-contained toolchains with emulators that reach the network, for programs that use FujiNet or the M4:

- [Atari XL + FujiNet](https://github.com/joergr72idb/development-kit-atari-xl-and-fujinet) -
  cc65, fujinet-lib, FastBasic, atari800 + FujiNet-PC
- [C64 + FujiNet](https://github.com/joergr72idb/development-kit-c64-and-fujinet) -
  cc65, fujinet-lib, VICE + FujiNet-PC (IEC)
- [Schneider CPC + M4](https://github.com/joergr72idb/development-kit-cpc-and-m4) -
  SDCC, RASM, iDSK, CPCSyntaxError, a C library for the M4
- [Apple II + FujiNet](https://github.com/joergr72idb/development-kit-apple2-and-fujinet) -
  cc65, fujinet-lib, cadius, FujiNet Go

#### Odds and ends

- [**Atari XL MQTT**](https://github.com/joergr72idb/atari-xl-mqtt) - an Atari XL with FujiNet
  publishes an MQTT topic to Home Assistant, straight from Atari BASIC
